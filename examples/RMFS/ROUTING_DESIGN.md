# RMFS 경로 선택과 예약 실험 설계

목표는 목적지까지의 예상 도착 시각을 줄이는 것이다. 현재 거리 기준 A*는 기준선으로 둔다. 통행 시간에는 주행, 회전, 예약 대기를 포함한다.

## 제어점과 선분 예약

- 로봇은 진입 전에 필요한 제어점, 물리 선분, 출구의 정차 공간을 요청한다. 제어기는 충돌하는 요청을 함께 승인하지 않는다. 반대 방향 arc가 같은 통로를 쓰면 같은 물리 자원을 예약한다.
- 제어점은 랙 외곽이 점을 완전히 지나면 해제한다. 교차로에서 대기 중인 로봇의 통과권은 앞 로봇의 랙 전체가 해당 교차점과 연결된 출구 선분을 벗어난 뒤 부여하는 보수적 정책을 첫 기준으로 삼는다.
- 긴 선분은 교차가 없는 곳에도 중간 제어점을 넣어 분할한다. 분할점이 대기 위치로 쓰이면 랙 전체의 정차 공간을 확인한다. 양방향 통로의 반대 방향 진입은 분할 후에도 별도로 조정한다. 분할 전후의 교차로 대기시간과 전체 완료 시간을 비교한다.

## A*로 후보 경로 생성

기존 최단거리 경로, 충돌 가능성이 있는 선분·노드에 비용을 더한 우회 경로, 필요한 경우 해당 자원을 제외한 경로를 후보로 만든다. 실제로 통행 불가능한 자원은 제외하고, 일시 점유 자원은 예상 해제 시각을 사용해 대기 비용을 추정한다. 교차점 공유나 사각형 랙의 swept path 중첩은 공간상 충돌 후보다. 두 로봇의 점유 시간까지 겹치는 경우에 대기나 우회를 평가한다. 원형 외접 도형은 후보를 빠르게 거르는 데 쓸 수 있으며, 최종 공간 판정에는 랙 사각형을 사용한다.

우회로가 없거나 지나치게 길면 기존 경로에서 유한한 대기를 후보로 유지한다. 두 경로의 예상 도착 시간이 비슷하면 기존 경로를 유지해 잦은 경로 변경을 줄인다. 여러 로봇에 동시에 경로를 확정할 때는 최신 예약 상태로 다시 검증한다.

## Snapshot으로 대기와 우회 비교

1. 현재 시각, 로봇 위치·속도·적재 상태·경로, 예약과 대기열, 예정 이벤트와 장애 상태를 같은 시점에 복제한다.
2. 동일한 스냅샷에서 기존 경로로 대기 후 통과하는 분기와 후보 우회 경로로 이동하는 분기를 각각 실행한다. 다른 로봇에는 같은 제어 정책과 외부 입력을 적용한다.
3. 충돌이나 교착이 발생한 분기를 제외하고 예상 도착 시각을 비교한다. 평가 시간 안에 진행할 수 없는 분기는 미완료로 기록한다. 실행 모델에는 선택한 경로와 예약 요청만 반영한다.
4. 돌발 정지나 예약 지연으로 예상 통과 시간이 바뀌면 후보를 다시 평가한다. 우회가 불가능하고 대기 종료도 예측할 수 없으면 안전 지점에서 상태 변화를 기다리고, 교착 여부를 별도로 판정한다.

첫 실험은 기존 창고 교차로에서 도착 시각이 다른 경우, 같은 경우, 앞 로봇이 예기치 않게 지연되는 경우를 비교한다. 각 실행에서 도착 시간, 대기시간, 추가 주행 거리, 재계획 횟수, 충돌과 교착 여부를 기록한다.
