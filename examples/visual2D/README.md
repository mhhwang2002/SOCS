# PySide6 AGV demo

Install the optional dependency and the local SOCS package:

```powershell
python -m pip install -e ".[visual2d]"
```

Run the demo from the repository root:

```powershell
python -m examples.visual2D.simple_demo
```

Click the scene and press **Space** to advance to the next destination. Use the
mouse wheel to zoom, right-button drag to pan, and **F** to fit the layout.
