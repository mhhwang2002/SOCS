# RMFS 오더 생성 사양

현재 실험은 시뮬레이션 시각 0에 초기 오더 100건을 한 배치로 생성한다. 모델 생성 옵션 `--orders`로 초기 건수를 바꿀 수 있다.

향후 시나리오에서 초기 배치와 반복 배치를 독립적으로 설정한다.

- 초기 배치는 생성 여부와 배치 크기로 정한다. 예를 들어 초기 생성이 켜져 있고 크기가 100이면 시각 0에 100건을 생성한다.
- 반복 배치는 생성 간격과 배치 크기를 지정한다. 간격은 고정 시간 또는 지정된 분포를 사용하고, 크기는 고정 정수 또는 지정된 분포에서 뽑은 정수다.
- 반복 생성을 끝내는 조건은 초기 배치를 포함한 누적 생성 건수 상한과 시뮬레이션 종료 시각이다. 둘을 함께 지정하면 먼저 충족되는 조건을 적용한다. 마지막 배치는 건수 상한을 넘지 않도록 줄이고, 종료 시각부터는 새 오더를 생성하지 않는다.
- 생성 종료 후에도 제어기에 도착한 오더는 처리 대상으로 남는다.

반복 배치와 종료 조건은 사양으로만 남겨 둔다.
