## 1. 모델과 용어 정리

**AchievedDate: 2026-11-19**

- 시간을 추상화하되 경로의 진행 순서를 유지하는 문제로 정리했다. **AchievedDate: 2026-11-19**
- 물체의 점유 영역, 부분경로 스윕, 점분스, 전체 스윕을 정의했다. **AchievedDate: 2026-11-19**
- 고정 방향의 사각형 물체가 축 방향으로 이동하는 RMFS 스윕을 직사각형들의 합집합으로 표현했다. 로봇이 회전해도 랙은 회전하지 않는 조건을 반영했다. **AchievedDate: 2026-11-19**
- 분스복은 점분스를 복사해 대기를 넣는 연산으로, 분스합은 원 경로의 중간점과 꺾임을 보존하면서 이동을 묶는 연산으로 구별했다. **AchievedDate: 2026-11-19**
- 짝경로를 n개 물체의 묶음경로로 확장했다. 각 성분은 부분경로이며, 점경로는 대기이다. **AchievedDate: 2026-11-19**

## 2. 무간섭 묶음경로의 실행 성질

**AchievedDate: 2026-11-19**

- 각 묶음에서 대기 물체의 점분스까지 포함해 모든 서로 다른 물체의 스윕이 무간섭이면, 그 묶음 실행은 물체 간 충돌을 일으키지 않음을 논증했다. **AchievedDate: 2026-11-19**
- 유한 개의 묶음을 순서대로 실행하고 각 이동이 유한시간에 완료되면 전체 경로도 충돌 없이 유한시간에 완료됨을 정리했다. **AchievedDate: 2026-11-19**
- 시작·종점의 점분스가 다른 물체의 전체 스윕과 무간섭인 강한 조건에서 분스복으로 완결 실행을 구성하는 충분조건을 정리했다. 필요조건이라고 주장하지 않는다. **AchievedDate: 2026-11-19**

## 3. 단위 경로쌍과 16가지 끝점 유형

**AchievedDate: 2026-11-19**

- 두 물체의 시작·종점 간섭 여부를 네 개의 이진값으로 표현해 16가지 유형을 분류했다. **AchievedDate: 2026-11-19**
- 하나의 연결된 공통 중심 부분경로 및 끝점 간섭에 관한 추가 가정 아래, 7가지 완결 가능 유형과 9가지 불가 유형의 분류 및 증명을 문서화했다. **AchievedDate: 2026-11-19**
- 시작 간섭쌍, 종착 간섭쌍, 막힘 간섭쌍을 구분했다. **AchievedDate: 2026-11-19**
- 중심 경로의 교집합, 스윕 교집합, 간섭 진행 구간은 일반적으로 같은 개념이 아님을 반례로 확인하고 적용 범위를 제한했다. **AchievedDate: 2026-11-19**

### 실험적 확인

4×4 점 격자, 간격 2m, 1.5m 정사각형 물체, 최대 5개 선분의 단순 경로라는 조건에서:

- 단위·독립 경로쌍 1,799,096개를 검사했다. **AchievedDate: 2026-11-19**
- 분류식과 별도 도달 가능성 검사 사이에 불일치가 없었다. **AchievedDate: 2026-11-19**
- 대표 320개는 실제 WaitDuplicationSolver와 교차 검증했다. **AchievedDate: 2026-11-19**

이는 해당 유한 실험 범위의 확인이며 임의의 스윕에 대한 전수 증명은 아니다.

## 4. 여러 물체의 선행 요구 관계

**AchievedDate: 2026-11-19**

- 쌍별 완결 가능성이 전체 물체의 완결 가능성을 보장하지 않음을 순환 대기 사례로 확인했다. **AchievedDate: 2026-11-19**
- 정적 직렬 통과 요구 관계와 현재 점유에 의한 실제 대기 관계를 구별했다. **AchievedDate: 2026-11-19**
- 정적 요구 그래프가 비순환이면 그 순서를 이용해 분스복으로 전체 완결 실행을 구성하는 충분조건과 증명을 정리했다. **AchievedDate: 2026-11-19**
- 정적 순환이 있어도 풀리는 예제를 확인했다. 따라서 정적 순환 검출을 일반적인 해 없음 판정으로 쓰지 않는다. **AchievedDate: 2026-11-19**

## 5. n개 물체의 분스합

**AchievedDate: 2026-11-19**

- 연속된 두 묶음의 성분별 연결 조건, 원 경로 순서를 보존하는 합 연산, 합친 스윕의 합집합 표현을 일반형으로 문서화했다. **AchievedDate: 2026-11-19**
- 합친 뒤 모든 서로 다른 물체 쌍이 무간섭이어야 하는 보수적인 합 허용 조건을 정리했다. **AchievedDate: 2026-11-19**
- 원래 두 묶음이 각각 무간섭일 때 추가로 검사할 교차 항을 명시했다. **AchievedDate: 2026-11-19**
- 유한시간 실행 가정 아래 안전한 합이 안전성과 전체 완료를 보존하는 성질과 증명을 적었다. **AchievedDate: 2026-11-19**
- 이 성질은 검증된 묶음들을 합해 실행하는 경우의 성질이다. 현재 비동기 제어 알고리듬 전체의 일반적 완료 보장을 증명한 것으로 확대하지 않는다. **AchievedDate: 2026-11-19**

## 6. 최근 합의한 구현 원칙과 관찰

**AchievedDate: 2026-11-19**

- 분스합은 이동 명령에 적용하고, 원 제어용 분스 및 출발 판단 규칙은 유지한다. **AchievedDate: 2026-11-19**
- 고정 경로에서 지나간 부분을 해제하면 잔여 간섭 그래프의 연결 성분은 작아지거나 분리된다는 논리를 확인했다. 정식 정의·정리·증명 문서화는 할 일로 남긴다. **AchievedDate: 2026-11-19**

- 목적지 도착 후에도 점분스는 남으며, 새 경로 배정 시에는 간섭 묶음이 다시 합쳐질 수 있다는 적용 경계를 확인했다. **AchievedDate: 2026-11-19**
